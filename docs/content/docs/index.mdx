**Open Reclamos** es una plataforma open source para crear y gestionar Libros de Reclamaciones Virtual alineado con las regulaciones de INDECOPI (Perú)

Esta documentación cubre las **integraciones**: cómo conectar Open Reclamos con
tus propios sistemas.
